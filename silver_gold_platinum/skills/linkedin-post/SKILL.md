# LinkedIn Post Skill

## Purpose
This skill posts content to LinkedIn on behalf of the user.

## Functionality
- Accepts post content (text, title, URL)
- Validates required fields
- Makes API call to LinkedIn to publish the post
- Returns success/failure status

## Input
- text: Main content of the post (required)
- title: Title of the post (optional)
- url: URL to include in the post (optional)

## Output
- Success message with post details on success
- Error message on failure
